# BHEL AI Strategy Research

`bhel-ai-strategy.html` is an independently-researched AI strategy report for BHEL (Bharat Heavy Electricals Limited), built entirely from public information — no BHEL internal data.

Covers: BHEL's strategic context and competitive landscape, the 2026 AI/industrial-AI landscape, a 114-item AI use-case map, a public-data-first opportunity shortlist, a recommended MVP, full system architecture (agent framework, knowledge graph, evidence system, tech stack), a 12-week delivery roadmap, governance/risk analysis, and a 3–5 year evolution path.

This report is the strategic basis for what this repository builds. Open the HTML file directly in a browser to read it.
